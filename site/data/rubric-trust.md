# 活动级信任两维度的编码口径

对象：O*NET 的 332 项中间工作活动（iwa_input.json）。设想把这项活动交给 Agent（受托方）代为完成，判定两个维度，各取 1～4 档的整数，按该活动最典型的情形判定。

## 违约后果（Agent 做错时，委托人的损失有多大、能否撤回）
1. 轻微且可撤回：重做即可，几乎无损失（如整理资料出错、草稿写差）。
2. 有损失但可以补救：浪费时间或少量费用，可更正、退回。
3. 损失较大、部分难以撤回：资金、声誉或健康受到可恢复但代价不小的损害。
4. 重大且不可撤回：成交、产生法律效力、身体伤害、安全事故、关系破裂等无法复原。

## 结果可验证性（单次产出的对错能否及时判定）
1. 长期才能判定：须数月以上或统计意义上才能判断对错（如教育成效、投资组合管理）。
2. 须专业判断：叙述性、判断性成果，对错要靠专业人员审阅。
3. 可逐事件核对：事后不久可以逐项核对。
4. 生效前当场可判定：生效前即可看清并核对（如有测试的程序、签字前可见的单据、可直接查看的数据）。

## 输出
JSON 数组，每项 {"id": "...", "cons": 1～4, "verif": 1～4, "note": "不超过 15 字的理由"}，恰好 332 项、id 与输入一一对应。
