# 中间工作活动（IWA）的判定口径

对每一项 O*NET 中间工作活动（IWA），判定两件事。

## 一、门（gate），只取一个值
依据“这项活动的直接结果改变的是哪一种状态”，与人类事务分类一致：
- 1：从业者本人保留的认知与决定：形成判断、作出决定、学习与更新知识、确定目标与策略，结果在从业者本人心中（亲历、亲定）。
- 2：他人身心与关系：沟通、解释、教学、照护、销售与说服、协调与管理他人、建立关系、为公众服务或表演。
- 3：物与环境：体力活动、搬运、操作机器与工具、驾驶、修理与安装、制作实物、清洁、种植与养殖、处理材料。
- 4d：信息，且输入已数字化或可经系统取得：记录、处理、分析、计算、设计、编写文档与程序、检索资料、制定计划与日程。
- 4s：信息，但须在现场以感官获取：观察、检查、测量物体、设备、场所或人的身体状况。
- 5：权利与义务：签订与谈判合同、采购与付款、审批与授权、录用人员、作出具有法律效力的裁决或执法、支配预算与资产、办理许可与申报。

## 二、Agent 可承担的比例 r（三档能力分别给值）
含义：在 Agent 能完整、正确履行的理论前提下，这项活动的工作时间中可交给 Agent 的比例；从业者仍须发起、核对与确认的部分不计入 r（那属于放大倍数中的核对投入）。只取 0、0.1、0.25、0.5、0.75、0.9 之一。
- 甲：通用数字 Agent。只有对话中提供的材料与公开信息，能生成文本、表格、代码与图像；不接入组织的数据与系统，不能对外行动。
- 乙：具备上下文与工具的数字 Agent。在甲之上，接入委托人与组织的数据与系统（文档、邮件、代码库、业务系统、传感器与摄像头的数据流），可执行代码，可经授权对外发送消息、经机构接口办理事务。
- 丙：在乙之上具备具身能力（通用机器人与联网设备），可在现场感知并作用于物。
判定要点：
- 须本人亲历、亲定的部分（门 1 的核心）、价值来自由谁完成的部分（私人关系、照护中的陪伴、面对面的信任）、法律要求本人实施的部分，r 应低。
- 门 3 的活动在甲、乙两档通常为 0，除非对象本身由数字系统控制（如经控制系统操作的设备）。
- 门 4s 的活动在甲档很低；乙档取决于现场是否已有传感器与影像数据；丙档较高。
- 不按今天的可靠性打折，可靠性另由放大倍数中的实测值反映。
